MULTI SOURCING

보관함 상품을
카페24 쇼핑몰로.

멀티소싱에서 편집한 상품명, 상세페이지, 이미지와 옵션을 카페24에 등록합니다.

멀티소싱 최신 버전이 설치된 브라우저에서 열어주세요.

처음 연결할 때

  1. 멀티소싱의 설정 → 카페24 API를 엽니다.
  2. 쇼핑몰 ID와 개발자 앱 정보를 입력하고 저장합니다.
  3. 카페24 연결을 눌러 운영자 계정으로 로그인하고 권한을 승인합니다.
  4. 보관함에서 상품을 선택한 뒤 카페24 업로드에서 내용과 판매 설정을 확인합니다.
앱 비밀키와 API 토큰은 이 웹사이트에 입력하지 않습니다. 멀티소싱 연결 도구가 PC에서 암호화해 보관합니다.
